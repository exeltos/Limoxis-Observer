# Μητρώα & δείκτες τμημάτων: απογραφή FileMaker και σχέδιο μεταφοράς

> Κατάσταση: ανάλυση για μελλοντική φάση. Πηγή: 22 στιγμιότυπα οθόνης από το τρέχον FileMaker (01–22).
> Σκοπός: να καταγραφεί τι τηρεί σήμερα κάθε τμήμα, τι προβλήματα υπάρχουν, και τι πρέπει να υποστηρίζει ένας γενικός μηχανισμός «μητρώα & δείκτες που ορίζει ο χρήστης» στο Limoxis Observer.

Τύποι:
- **Α — ανά περιστατικό**: μία φόρμα ανά ασθενή/νεογνό/πράξη· οι δείκτες υπολογίζονται από τις εγγραφές.
- **Β — συγκεντρωτικό**: αριθμοί ανά κατηγορία για μια ημερομηνία/βάρδια/μήνα· οι δείκτες είναι αθροίσματα και ποσοστά.
- **Σ — οθόνη σύνοψης**: αναδυόμενο παράθυρο με τους υπολογισμένους δείκτες του μητρώου.

Γενική παρατήρηση: **σε καμία σύνοψη δεν φαίνεται φίλτρο περιόδου**. Τα σύνολα (π.χ. 3579 νεογνά, 5021 τοκετοί) μοιάζουν να αφορούν όλο το ιστορικό, χωρίς στόχο, όριο ή σύγκριση.

## 4. Σχέδιο: μητρώα & δείκτες που φτιάχνει ο ίδιος ο χρήστης

### 4.1 Ορισμός μητρώου (τύπος Α)

- **Κεφαλίδα**: τμήμα, όνομα, έκδοση ορισμού (οι αλλαγές δεν «σπάνε» παλιές εγγραφές), κατάσταση (πρόχειρο/ενεργό/αρχειοθετημένο).
- **Σύνδεση ασθενούς** (προαιρετική): αρ. μητρώου/περιστατικού → τα στοιχεία ταυτότητας έρχονται από Ασθενείς και δεν ορίζονται ως πεδία του μητρώου.
- **Πεδία**, με ενότητες (όπως οι τρεις ενότητες της ΜΕΝΝ):

| Τύπος | Ρυθμίσεις |
|---|---|
| Αριθμός | μονάδα, δεκαδικά, min/max (σφάλμα), εύλογο εύρος (προειδοποίηση) |
| Ημερομηνία / ημερομηνία-ώρα | κανόνες σε σχέση με άλλα πεδία (≥ εισαγωγή) |
| Ναι/όχι | με ή χωρίς «άγνωστο» |
| Λίστα μονής / πολλαπλής | πηγή: βιβλιοθήκη Observer (φύλο, εκβάσεις, προσωπικό, ICD-10) ή λίστα του μητρώου |
| Κείμενο | σύντομο / πολλών γραμμών· σημαία «μπορεί να περιέχει προσωπικά δεδομένα» |
| Υπολογιζόμενο | διαφορά ημερομηνιών (ημέρες/ώρες), ηλικία, κατάσταση από κανόνα, απλός τύπος (π.χ. APACHE II → %) |
| Σύνδεση με άλλη ενότητα | «λοίμωξη από Επιτήρηση», «καλλιέργεια από Εργαστήριο» — μόνο ανάγνωση |

- Κάθε πεδίο: ετικέτα, κωδικός (σταθερός, για εισαγωγή/εξαγωγή), υποχρεωτικό, βοήθεια/ορισμός, ορατότητα υπό συνθήκη (π.χ. EUROSCORE μόνο όταν ΚΑΤΗΓΟΡΙΑ = Καρδιοχειρουργική).

### 4.2 Ορισμός μηνιαίου φύλλου (τύπος Β)

- **Περίοδος**: μήνας (προεπιλογή), ημέρα ή βάρδια (με λίστα βαρδιών)· μοναδική εγγραφή ανά τμήμα+περίοδος.
- **Γραμμές** = κατηγορίες (Καταράκτες, Βιτρεκτομές…), με ομάδες (Τοκετοί / Λοιπές πράξεις).
- **Στήλες** = μέτρα (π.χ. «Αριθμός», ή «Προγραμματισμένα / Έκτακτα»)· ακέραιοι ≥ 0.
- Κενό ≠ 0· «κλείσιμο περιόδου» από τον υπεύθυνο τμήματος (κλείδωμα, διορθώσεις με αιτιολογία).
- Ημερήσια/βάρδιας καταχώριση αθροίζεται αυτόματα σε μήνα για τους δείκτες.

### 4.3 Ορισμός δείκτη

| Στοιχείο | Περιγραφή |
|---|---|
| Πηγή | μητρώο Α ή φύλλο Β (ή Επιτήρηση για ημέρες συσκευής/λοιμώξεις) |
| Συνάθροιση | πλήθος, άθροισμα, μέσος όρος, διάμεσος, % (αριθμητής/παρονομαστής), ρυθμός ανά 1000 (ημέρες), λόγος (SMR) |
| Αριθμητής | φίλτρο εγγραφών (π.χ. ΕΙΔΟΣ ΤΟΚΕΤΟΥ = Κ/Τ, VAP = ναι) |
| Παρονομαστής | πλήθος εγγραφών με φίλτρο, ή άθροισμα πεδίου (ημέρες αναπνευστήρα) |
| Ομαδοποίηση | ανά τιμή λίστας (ιατρός, πράξη, φύλο) — αντί για «σκληρές» γραμμές |
| Ημερομηνία αναφοράς | ποιο πεδίο ορίζει την περίοδο (εισαγωγή ή έξοδος) |
| Περίοδος | μήνας / τρίμηνο / εξάμηνο / έτος |
| Χειρισμός κενών | αποκλεισμός ή ρητή γραμμή «χωρίς τιμή» |
| Στόχος & όριο | τιμή, κατεύθυνση (↑ ή ↓ καλύτερο), μονάδα |
| Παραβίαση ορίου | ειδοποίηση + **προτεινόμενη CAPA** (ο χρήστης επιβεβαιώνει, δεν ανοίγει αυτόματα) |
| Σύνδεση | Δείκτες → Στόχοι → Ανασκόπηση Διοίκησης → συνεδρίαση τμήματος |

Παραδείγματα ορισμών: «% Κ/Τ στη ΜΕΝΝ» = πλήθος(ΕΙΔΟΣ ΤΟΚΕΤΟΥ = Κ/Τ) ÷ πλήθος(ΕΙΔΟΣ ΤΟΚΕΤΟΥ μη κενό)· «VAP ανά 1000 ημέρες αναπνευστήρα» = πλήθος VAP (Επιτήρηση) ÷ Σ ημερών αναπνευστήρα × 1000· «Μέση διάρκεια νοσηλείας ΜΕΝΝ» = μέσος(ΔΙΑΡΚΕΙΑ ΝΟΣΗΛΕΙΑΣ) με φίλτρο «έχει έξοδο», ημερομηνία αναφοράς = έξοδος.

### 4.4 Αναφορές

- Επιλογή περιόδου και τμήματος (ή πολλών), επιλογή δεικτών.
- Πίνακας και γράφημα (τάση ανά μήνα με γραμμή στόχου/ορίου, κατανομή ανά κατηγορία).
- Σύγκριση με προηγούμενη περίοδο και ίδια περίοδο προηγούμενου έτους.
- Εξαγωγή PDF (για συνεδρίαση/Ανασκόπηση) και Excel (δεδομένα δεικτών, όχι ονόματα).
- Αποθηκευμένα πρότυπα αναφορών ανά τμήμα.

### 4.5 Ρόλοι

| Ρόλος | Ορίζει μητρώα/δείκτες | Καταχωρεί | Βλέπει ονόματα | Βλέπει δείκτες |
|---|---|---|---|---|
| Ομάδα Ποιότητας | ναι (ορισμοί, στόχοι, όρια) | όχι | **όχι** | όλα τα τμήματα |
| Υπεύθυνος τμήματος | προτείνει αλλαγές· κλείνει περίοδο | ναι | ναι (δικό του τμήμα) | δικό του τμήμα |
| Καταχωρητής τμήματος | όχι | ναι | ναι (δικό του τμήμα) | δικό του τμήμα |
| Διοίκηση | όχι | όχι | όχι | συγκεντρωτικά |
| Επιτροπή Λοιμώξεων | όχι | όχι | όχι (ή μέσω Επιτήρησης) | δείκτες λοιμώξεων |

Κανόνες: δείκτες με μικρό πλήθος (π.χ. < 5) εμφανίζονται με επισήμανση· ΑΜΚΑ δεν εμφανίζεται σε καμία εξαγωγή· οι ορισμοί έχουν ιστορικό αλλαγών.

### 4.6 Εισαγωγή από FileMaker

1. Εξαγωγή κάθε πίνακα σε CSV/Excel (με ονόματα πεδίων στην πρώτη γραμμή).
2. Οδηγός εισαγωγής: επιλογή μητρώου → αντιστοίχιση στηλών σε πεδία (αυτόματη πρόταση από ετικέτες) → αντιστοίχιση τιμών λιστών (π.χ. «Φ/Τ» → Φυσιολογικός τοκετός, «Α.Τ» → Αίθουσα Τοκετών).
3. Μετατροπές: «3320 Kg» → 3320 g, «37,4 w» → 37+4, «44 ετών» → 44, HFOV ΝΑΙ/ΟΧΙ → ένα πεδίο, ημερομηνίες d/m/yyyy.
4. Δοκιμαστική εκτέλεση με αναφορά σφαλμάτων (εκτός ορίων, άγνωστη τιμή λίστας, ΦΥΛΟ = «90», εγγραφές «ΤΕΣΤ») πριν την οριστική εισαγωγή.
5. Επαλήθευση: οι δείκτες στο Observer για την ίδια περίοδο συγκρίνονται με τις συνόψεις του FileMaker· οι διαφορές τεκμηριώνονται (αναμένονται εκεί που ο FileMaker έχει λάθος τύπο).

### 4.7 Σειρά πιλότου

1. **ΜΕΝΝ (τύπος Α)** — τα περισσότερα είδη πεδίων, υπολογιζόμενα, σύνδεση με Επιτήρηση (λοιμώξεις, ημέρες καθετήρα), άμεσα χρήσιμη για Λοιμώξεις.
2. **Οφθαλμολογικό ή Ενδοσκοπικό (τύπος Β)** — απλό φύλλο, γρήγορη επικύρωση του μηχανισμού φύλλων.
3. Στη συνέχεια ΜΕΘ (ρυθμοί ανά 1000 ημέρες, SMR), Μαιευτική + Αίθουσα Τοκετών μαζί (εξάλειψη διπλοκαταγραφής), Αιμοδυναμικό (πολλαπλή επιλογή), Χημειοθεραπεία, Παιδιατρική, ΤΕΠ.
