# v0.26.26 — Indicator builder
- Added New Indicator through shared Create action.
- Automatic custom indicators can be built from the metric catalog using numerator, optional denominator and multiplier.
- Manual indicators are supported when the source is external/not yet integrated.
- Custom definitions persist in local storage.
- New automatic indicators require no code change when the needed data metrics already exist.
- A genuinely new source/metric requires one integration into the metric catalog; after that it can be reused by many indicators.
- Simplified indicator detail card to emphasize current value, target, source, formula and traceability.
